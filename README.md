## How I Work With AI

1. Define the goal, constraints, and expected user behavior.
2. Turn requirements into clear prompts and acceptance criteria.
3. Review AI-generated outputs and compare them with the requirements.
4. Test key workflows, edge cases, and failure scenarios.
5. Report inconsistencies and refine prompts or requirements.
6. Re-test revised outputs to check whether the issues were addressed.

My application projects were built primarily with AI assistance through prompts. I focus on requirements, hands-on testing, output review, and iterative refinement; I do not present this work as professional software engineering experience.
